# NEXO IA 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrar descoberta, ranking, cards, ações, analytics e histórico efêmero no fluxo real da NEXO.

**Architecture:** Funções puras concentram classificação, contrato, ranking e rotas. O Worker faz auth/retrieval/orquestração; Supabase persiste eventos e preferências; a SPA renderiza e executa o contrato.

**Tech Stack:** JavaScript ESM/CommonJS, Cloudflare Workers, Supabase/Postgres/RLS, SPA hash-router.
